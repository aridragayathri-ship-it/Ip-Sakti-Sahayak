    About

    About this prototype

    IP-SAKTI was built as a Smart India Hackathon prototype to demonstrate how an AI assistant could help Ayurvedic innovators navigate intellectual property and regulatory questions.

    What this is

    A front-end-only demo with dummy AI responses, sample citations, and browser-local authentication — built to show the intended user experience.

    What this isn't

    There is no real backend, no real AI model call, no verified legal database, and no real user accounts behind this build.
